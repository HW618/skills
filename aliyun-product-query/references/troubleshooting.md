# 抓取故障排查

## 常见错误

### HTTP 403 / Forbidden

阿里云对高频请求或可疑 UA 可能返回 403。

**处理**：
1. 等待 1-2 分钟后重试
2. 用浏览器工具降级抓取（浏览器有真实浏览器指纹）
3. 检查是否短时间内请求过多

### 内容含验证码特征

`fetch_page.py` 会检测"验证码""captcha"等关键词并判定失败。

**处理**：
1. 用浏览器工具降级，人工或自动完成验证码
2. 完成后用 `read_page` 读取内容

### 内容过短（<100 字节）

可能是重定向到错误页或空响应。

**处理**：
1. 检查 URL 是否正确（产品 key 是否拼写正确）
2. 用 `curl -I` 检查响应头和重定向链
3. 浏览器降级

### curl 超时

网络问题或阿里云响应慢。

**处理**：
1. 增加 `--timeout` 参数（默认 30 秒）
2. 检查网络连接
3. 重试

## 浏览器降级流程

当 `fetch_page.py` 失败时，按以下步骤用浏览器工具抓取：

1. `open_browser_page` 打开目标 URL
2. 等待页面加载完成
3. `read_page` 获取页面快照
4. 从快照中提取 markdown 文本内容
5. 写入目标文件路径

**防反爬手段**：
- 使用真实浏览器 UA（浏览器工具自带）
- 请求间合理延时（1-2 秒）
- 避免短时间内大量请求同一域名
- 如遇验证码，暂停等待用户处理或降速

## 产品 key 查找

若不确定产品的 llms.txt URL：

1. 读 `cache/_index/navigation.md`
2. 搜索产品名（如"轻量应用服务器"）
3. 找到形如 `https://help.aliyun.com/zh/<key>/llms.txt` 的链接
4. `<key>` 即为产品 key

## 缓存损坏恢复

若缓存文件损坏或不一致：

1. 删除 `cache/<product>/` 目录
2. 重新运行 `python scripts/update_index.py --product <key>`
3. 或删除整个 `cache/` 重新 `--init`
